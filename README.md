# Tailor Shop Management System

A desktop application for managing a tailor shop, including customer information, repair services, billing, and label printing.

## Features

- Customer management (add, edit, search, view history)
- Service management (predefined repair types with pricing)
- Transaction processing (calculate bills based on selected services)
- Label printing for clothes (10x5 cm format)
- Customer database with search functionality

## Installation

1. Make sure you have Python 3.8+ installed
2. Install required dependencies:
   ```
   pip install -r requirements.txt
   ```
3. Run the application:
   ```
   python src/main.py
   ```

## System Requirements

- Windows/macOS/Linux
- Python 3.8 or higher
- Qt6
- Label printer (for printing tags)
